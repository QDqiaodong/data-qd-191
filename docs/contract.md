# 保留时间积分与定量 v1

教学离线JSON模型：analytes为1..30个唯一ASCII id及window=[lo,hi]（0≤lo<hi）；runs为1..200个唯一id、kind=standard/unknown和2..2000个[t,y]采样。t非负严格递增；所有运行必须完整覆盖所有分析物窗口，不隐式外插信号。数值均有界十进制字符串（最多9位整数6位小数）。时间、响应、浓度单位由调用方统一给定；软件不推断真实仪器单位。

对每个窗口在原分段线性信号上插值端点；连两端点作为线性基线，扣基线后逐段梯形积分，保留负值。积分区间可重叠，各分析物独立，不做去卷积或分峰。apex取所有窗口端点/内部采样中扣基线高度最高者，平局最早时间；这不替代真实峰检测。逐段area可复加验证，不截断负值。

标准品必须给全部分析物的非负concentrations；未知样不得带已知浓度。每分析物至少两条标准且浓度不全相同，对area=slope×concentration+intercept作等权最小二乘（含截距、重复标准独立计权）。要求slope>0，否则整批失败。输出残差和平方和。不隐式扣空白、不强制过原点、不做加权或稳健拟合。

未知样浓度=(area-intercept)/slope，精确Fraction输出整数/分数字符串；超标准浓度范围标extrapolated，负浓度保留并标negative，不悄悄归零。以上属于业务诊断，退出0。没有真实实验、检测认证或化学操作指导；无仪器格式解析、峰自动识别、稀释/内标/检出限模型。结构、覆盖、校准不可辨识或响应错误退出2；先完整计算再原子新建JSON，拒绝已有文件及链接。
